# Zombie Shelter

Zombie Shelter is a cooperative tower defense styled gamemode, Inspired by CSN's Zombie Shelter gamemode, You need to survive to day 30 or call for rescue on day 15
If your shelter is destroyed, you lose

* Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3313743318

## Features

* **Looking to play list**: You can join other player's game with looking to play feature
* **Building System**: You can build defensive turrets or barricades to protect your base from being destroyed by zombies
* **Customizable Enemies & Weapons**: Gamemode has a built-in config menu allows you to customize every weapons and enemies in game
* **Skilltree System**: There's 3 classes, Combat, Survival, Engineer, Each class has it's unique skills and playstyle, you gain skillpoints everyday, spent it wisely
* **Dynamic Enemies Spawn**: Enemy spawns at random location, Means they are unpredictable
* **Dynamic Difficulty Scaling**: Game director will dynamically spawn enemies depends on how well players are playing
* **Multiplayer Difficulty Scaling**: Game's difficulty and resource costs when upgrading shelter will scale with player amount
* **Works on any map with AI nodes**: Gamemode works on any map with AI nodes, but you'll need to manually set some required entity on unofficial map
* **In-Game Map Editor**: You can edit where shelter and enemy spawns with in-game editor, only works on unofficial maps
* **External Config Support**: You can download and play with other player's config from workshop
